
Para ir a version 2 (desarrollo) y modificar codigo:
    git checkout v2-evolucion
    git merge stable

    Para chequear la version 2 en el movil
        npm run dev -- --host (Ctrl - C para cerrar el host)
        abrir la IP en el navegador del movil (mismo Wifi)

    Cuando acabemos los cambios
        git checkout stable
                            opcional git pull (para traer la ultima version del repo)
        git merge v2-evolucion

        node scripts/convertirExcel.js
        npm run build
        npm run deploy

        git push
 

Si quiero actualizar la base de datos o ver los ultimos cambios en la app
    node scripts/convertirExcel.js
    npm run build
    npm run deploy

**Si he hecho cambios en la app y quiero cargarlos a github
    git add .
    git commit -m "Ultimos cambios"
    git push

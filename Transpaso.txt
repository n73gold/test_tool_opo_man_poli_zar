# 📚 Proyecto: App de Test de Oposición

---

# 1. Tecnologías

Frontend:

* **React + Vite**
* JavaScript
* Recharts (estadísticas)
* LocalStorage (persistencia)

Datos:

* Preguntas en **Excel**
* Convertidas automáticamente a **JSON**

La app es:

```text
100% frontend
sin backend
funciona offline
```

Optimizada para **uso móvil (iPhone principalmente)**.

---

# 3. Flujo de datos

Pipeline de generación de preguntas:

```text
Excel
   ↓
convertirExcel.js
   ↓
preguntas.json
   ↓
App React
```

El script:

* convierte Excel → JSON
* incrementa versión automáticamente

---

# 4. Sistema de versión automática

Cada vez que se ejecuta:

```bash
node scripts/convertirExcel.js
```

ocurre:

1️⃣ Se genera `preguntas.json`
2️⃣ Se incrementa la versión automáticamente
3️⃣ Se actualiza la versión visible en la app

Ejemplo:

```text
v1.0.12 → v1.0.13
```

La versión se muestra en la **pantalla HOME**.

---

# 5. Sistema de actualización de preguntas

Al iniciar la app:

1️⃣ intenta cargar preguntas desde **localStorage**
2️⃣ intenta descargar `preguntas.json`
3️⃣ si hay versión nueva → actualiza
4️⃣ si no hay internet → usa las guardadas

Esto permite:

```text
uso offline
autoactualización cuando hay red
```

# 7. Modos de test

La app tiene **3 modos principales**.

---

## 🟢 Modo práctica

Características:

* feedback inmediato
* colorea respuestas
* no permite cambiar respuesta
* obliga a responder antes de avanzar
* permite explicación con IA

---

## 🟡 Modo examen

Características:

* test de **20 preguntas**
* no muestra respuesta correcta hasta el final
* permite revisión posterior

---

## 🔵 Modo oposición

Simula examen real.

Características:

* **50 preguntas**
* permite dejar preguntas en blanco
* sistema de penalización

Cálculo:

```text
nota = (correctas - incorrectas/3) / 5
```

Incluye:

* pantalla de repaso
* navegación directa por pregunta
